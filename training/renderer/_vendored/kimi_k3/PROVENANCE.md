# Vendored Kimi K3 encoder

`encoding_k3.py` is a byte-for-byte copy of the upstream Kimi K3 XTML chat
encoder, incorporated as reviewed package source so that renderer tokenization
never fetches or executes checkpoint Python at runtime.

| License | Kimi K3 License (see `LICENSE`, copyright 2026 Moonshot AI) |
| Retrieved | 2026-11-05 |

The sha256 above is identical to the constant `KIMI_K3_ENCODER_SHA256` in
`training/renderer/kimi_k3.py`; a unit test asserts the vendored file still
hashes to it.

Static inspection at incorporation (26311 bytes): imports limited to
`__future__`, `json`, `dataclasses`, `typing`; no I/O, no `exec`/`eval`, no
subprocess, no network, no third-party dependencies.

Do not edit this file. To move to a newer upstream revision: download the
exact new revision, verify its sha256, statically inspect it, replace this
file, and update `KIMI_K3_ENCODER_SHA256` and this document in the same
change.

Note: the Kimi K3.1 encoder is vendored separately under
`training/renderer/tito/_vendored/kimi_k31/` (pin
`367f0a7ab8800f78f7e09dc31e58544ee7fc46eea992ea05b32d53506a921cc5`). The two
encoders are distinct rendering contracts -- K3.1 renders non-string tool
arguments from their JSON literal bytes --
and must not be aliased.
