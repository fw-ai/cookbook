# Caveman v2c teaching bundle

Frozen final inputs and compact evaluation evidence, captured October 18, 2026.
Training has 2,348 accepted rows. The dev and test files each have 392 fixtures.
`manifest.json` records file hashes and training settings. Original fictional fixtures are
intended for Apache-2.0 release with the cookbook; the teacher skill retains its MIT license
and pinned revision in `../../sources/SOURCE.md`. Complete public licensing review before release.

`recorded.json` retains all 9,408 draw-level pass/word observations and two full answer examples
from the October 17 v2c evaluation. It supports the notebook's descriptive charts and grouped
bootstrap; it is not a replacement for all original responses if re-judging the study is needed.
The test was used by both v2b and v2c. Do not call it a once-only confirmatory test.
The base arm is bare base. This bundle contains no training credentials or service resources.

## Recorded study cost

Development and evaluation totaled 84.76 USD: 20.80 USD for data generation and filtering,
22.64 USD across five training runs, and 40.22 USD across seven evaluations. These are
historical ledger estimates, not a current quote or an invoice. The notebook supplies the
prepared data and selected settings, so learners need not repeat the research sweep.
The complete cost of that learner path has not yet been measured.

For provenance only: the selected run completed 74 steps with 526,162 training tokens.
At the study's 8.89 USD per million training tokens, its training-only estimate is 4.68 USD.
That excludes data preparation and evaluation and must not be presented as the adapter's build cost.

## Teaching example

`teaching_trace.json` contains aggregate training-selection counts and one complete four-candidate
example from the final builder outputs. It is a teaching extract, not a dependency on the historical
run folders. The notebook shows how a literal check rejected otherwise plausible answers.

The shared inference ledger pools multiple evaluations without run identifiers. It does not establish
a separate cost for the exact four-draw learner evaluation. End-to-end learner wall time also remains
unverified; do not label a combined cost or duration as measured until rehearsed.
